## Focus

I keep sec-skills as one place for reusable operational skills instead of repeating the same setup across different agents and projects.

---

## Current set

The current skills stay narrow and practical: `skill-scanner-scans` for suspicious skill review, `git-guard` for blocking dangerous git commands, and `devil-advocate` for stress-testing plans and designs.

---

## Reference

The main benefit is portability. The same skills can be installed through different paths, which keeps the workflow consistent even when the agent changes.
